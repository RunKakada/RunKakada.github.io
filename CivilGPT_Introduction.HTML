🏗️ CivilGPT

AI Assistant for Civil and Structural Engineering

CivilGPT is an AI-powered assistant designed for civil and structural engineering. It uses Large Language Models and Retrieval-Augmented Generation to help engineers ask questions, retrieve engineering knowledge, and generate clear, technical answers based on civil engineering documents, design codes, and construction references.

The goal of CivilGPT is to support engineers, students, and researchers in understanding structural design concepts, construction methods, code requirements, and engineering workflows more efficiently.

🚀 Key Features

  • Natural-language Q&A for civil engineering topics
  • RAG-based document retrieval from engineering PDFs
  • Support for structural codes such as ACI, ASCE, Eurocode, and AISC
  • FastAPI backend with React frontend
  • Gemini / OpenAI / Claude / local LLM support
  • Source-based answers with retrieved document references

🧠 Technology Stack

  • Frontend: React
  • Backend: FastAPI
  • LLM: Gemini / OpenAI / Claude / Llama
  • RAG Framework: LangChain
  • Vector Database: ChromaDB
  • Embeddings: HuggingFace / OpenAI Embeddings

🎯 Project Vision

CivilGPT aims to become a domain-specific AI engineering assistant that can support structural design, construction planning, code interpretation, BIM workflows, and engineering education.

“Building the future of AI-assisted civil engineering.”
